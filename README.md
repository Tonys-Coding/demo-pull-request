# UTD Student Starter Kit

A small student resource website for a one-hour open-source contribution workshop.
Practice choosing an issue, requesting approval, making a focused change, and opening a pull request.
This is a student-made learning project, not an official UTD website.

## Technology

Plain HTML, CSS, and JavaScript. No package installation, build step, database, or API keys.

## Quick start

Download or clone the repository and open `index.html` in a browser.
See [CONTRIBUTING.md](CONTRIBUTING.md) for the contribution workflow.

| `workshop/ISSUES.md` | Issue catalog with links to copyable issue bodies |

## Workshop starter status

The page works as a static resource list. The category dropdown and random-tip button
are intentionally disabled until contributors implement their issues. The card grid
also has a mobile-layout improvement available. These are scoped learning tasks.

## Contributing

Choose one available issue and comment to request it. Wait for an organizer to approve
before working. Keep each pull request focused on one issue.
