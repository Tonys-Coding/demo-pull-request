# UTD Student Starter Kit

A small student resource website for a one-hour open-source contribution workshop.
Practice choosing an issue, making a focused change, and opening a pull request.
This is a student-made learning project, not an official UTD website.

## Technology

Plain HTML and CSS. No package installation, build step, database, or API keys.

## Quick start

See the [live site](https://awesomness560.github.io/demo-pull-request/).
You make every change on the GitHub website, so there is nothing to download or clone.
See [CONTRIBUTING.md](CONTRIBUTING.md) for the contribution workflow.

## Project files

| File | Purpose |
|---|---|
| `index.html` | Page content, resource cards, and study tips |
| `styles.css` | Colors, spacing, and layout |
| `CONTRIBUTING.md` | Step-by-step contribution guide |

## Contributing

Choose one available issue and comment to claim it. Keep each pull request focused
on one issue. Each issue points to one slot or section, so contributors do not get
in each other's way.
